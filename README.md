# Pandal Hopping Guide

Static multi-page site for GitHub Pages. Upload everything in this folder to the root of your repository.

- `index.html` festival hub (off-season home page)
- `kali-puja-2026/`, `bhai-phota-2026/` festival guides
- `durga-puja-2026/` the Durga Puja 2026 site, kept as it was
- `wishes/`, `stories/`, `privacy/`, `terms/`
- `sitemap.xml`, `robots.txt`, `assets/`, `images/`

Site address used in links and previews: https://pandalhoppingguide.co.in

`CNAME` tells GitHub Pages to serve this site on pandalhoppingguide.co.in. The domain's DNS must point to GitHub Pages and the domain must not be on hold at GoDaddy.
